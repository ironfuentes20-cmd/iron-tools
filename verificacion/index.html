Hasta dónde llega esto

Esto es lo que ejecutamos, no una comprobación independiente: el repositorio es privado, así que nadie de fuera puede correr el mismo comando sobre el mismo commit y comparar. El identificador está publicado para que, con acceso al repositorio, cualquiera pueda hacerlo. Un auditor externo señaló justamente este punto y tiene razón en señalarlo.
