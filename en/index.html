How this page is built

Next.js and TypeScript, with no third-party charting library: the graphics are hand-written SVG. The computation lives apart from the interface and is tested without a browser. There are no accounts, no data server and nothing of yours is stored.

What is checked before publishing — the command, the commit and the result of all 355 tests.
